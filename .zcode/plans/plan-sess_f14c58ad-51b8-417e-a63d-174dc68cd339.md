## Sitemap ve SEO İyileştirme Planı

### 1. Sitemap Düzeltmeleri (Acil)
- **HTTP Method Fix**: `server/index.js` satır ~1283'te `app.get('/api/seo/sitemap')` → `app.post` olarak değiştir
- **Public sitemap route**: `GET /sitemap.xml` endpoint'i ekle — `public/sitemap.xml` dosyasını okuyup serve etsin
- **Hash URL'leri temizle**: Sitemap XML'inde `/#/urun/123` yerine gerçek path'leri kullan
- **Otomatik sitemap yenileme**: Ürün/blog/sayfa CRUD işlemlerinde sitemap'i otomatik yenile

### 2. SEO İyileştirmeleri
- **BreadcrumbList JSON-LD**: Sayfalara breadcrumb structured data ekle
- **Canonical URL tutarlılığı**: Tüm sayfalarda canonical etiketlerini düzgün ayarla
- **SEO Analizi iyileştirmeleri**: Admin panelindeki SEO analiz sekmesini güncelle
- **Sitemap index yapısı**: Ürünler, blog, sayfalar için ayrı sitemap'ler + ana sitemap index
